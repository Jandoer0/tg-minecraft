# Бот для управления сервером Minecraft 🎮

Этот бот предоставляет удобный интерфейс в Telegram для управления сервером Minecraft, развернутым через Podman. Он позволяет администраторам управлять состоянием сервера, переключать карты и мониторить онлайн игроков, не заходя в терминал.

## ✨ Функционал
- **Управление сервером**: Старт, Стоп и Рестарт.
- **Управление картами**: 
  - Просмотр списка всех доступных карт.
  - Смена текущей карты с автоматическим перезапуском сервера.
  - Создание новой карты прямо через бота.
  - Удаление ненужных карт.
- **Мониторинг**: Список игроков, находящихся в онлайне.
- **Безопасность**: Доступ только для пользователей, указанных в списке `TELEGRAM_ALLOWED_USERS`.
- **Стабильность**: Использование FSM для поддержки нескольких пользователей одновременно и HTML-разметки для корректного отображения имен карт.

## 🛠 Технический стек
- **Язык**: Python 3.13
- **Библиотека**: `aiogram` (асинхронный Telegram API)
- **Деплой**: systemd user unit (`bot-minecraft.service`)
- **Инфраструктура**: Контейнеры Podman (сервер Minecraft развернут через Quadlet)

## 🚀 Установка (упрощенно)
1. Клонируйте репозиторий на ваш сервер.
2. Создайте файл `.env` на основе `.env.example` и заполните его своими данными.
3. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r bot/requirements.txt
   ```
4. Скопируйте `bot-minecraft.service` в `~/.config/systemd/user/`.
5. Перезагрузите конфигурацию systemd и запустите бота:
   ```bash
   systemctl --user daemon-reload
   systemctl --user enable --now bot-minecraft.service
   ```

## 📝 Примечание
Бот должен быть запущен на том же хосте, где работают контейнеры Podman, чтобы иметь прямой доступ к `systemctl` и файловой системе сервера.
